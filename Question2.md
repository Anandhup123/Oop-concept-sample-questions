**Practical Problem Statement:**

Design a system for a **Student Management Application** using the concept of encapsulation in JavaScript. The system should:

1. Allow creating a `Student` class with the following private fields:
   - `name` (string): The name of the student.
   - `age` (number): The age of the student.
   - `grades` (array): A list of grades for the student.

2. Provide the following methods:
   - A getter for the student's name.
   - A getter and setter for the student's age (ensure the age is a positive number).
   - A method to add a grade to the `grades` array.
   - A method to calculate and return the average grade.

3. Ensure that the private fields cannot be accessed directly from outside the class.
